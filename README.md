# Antidepressant Utilization Patterns in Major Depressive Disorder: A Real-World Evidence Study using the OMOP CDM at Hospital del Mar

This github repository includes the code to reproduce the results from the Master's Thesis Project "Antidepressant Utilization Patterns in Major Depressive Disorder: A Real-World Evidence Study using the OMOP CDM at Hospital del Mar".

To reproduce the results, download the repository, open the `IMASIS_MDD.Rproj` file and run `R/MDD_AD_IMASIS.R` script.

Version information about R, the OS and attached or loaded packages can be found in the `sessionInfo.txt` file.
